## 4. 执行中发现并修复的问题

| 问题 | 说明 | 修复 |
|---|---|---|
| 启动时不校验登录态（P1-T5 暴露） | `btnLoaded` 被持久化后，带失效 token 启动不会请求后端，无法及时跳登录 | 新增内存态 `sessionChecked`：应用启动后首次进入业务页强制调用按钮权限接口校验登录态；失败可重试 |
| 构建警告 `INEFFECTIVE_DYNAMIC_IMPORT` | `request.js` 动态导入 router 分包告警 | 改为事件驱动（`jsh:login-out`）+ `main.js` 统一处理重置与跳转，消除循环依赖与告警 |
