> 注意（后端库存机制）：商品选择的"库存"读取 `jsh_material_current_stock` 缓存表，该表在单据保存/删除时重算（= 期初库存 + 单据流水）。
> 仅通过 SQL 写入期初库存不会立即刷新缓存；本次通过"新建并删除一张临时其它入库单"触发重算，最终 `current_stock=100`，与期初一致。
> 后续阶段建单/审核会自然维护该缓存，无需手工处理。

## 5. 执行中发现并修复的问题

| 问题 | 说明 | 处理 |
|---|---|---|
| 测试数据库存不生效 | 期初库存通过 SQL 写入，`current_stock` 缓存未刷新，接口库存为 0 | 通过建/删临时其它入库触发缓存重算，最终库存 100；已在本文件与 26 号文档说明 |
| 演示页价格显示无小数 | 演示页直接输出数字（10 而非 10.00） | 演示页统一 `toFixed(2)` |
| 首次运行页面重载 | Vite 新依赖优化导致 `Failed to fetch dynamically imported module`（仅首次） | 预热一次即稳定；已记录到常见问题 |
